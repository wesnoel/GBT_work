Concept A — Tooltip

The current pattern. A lightweight popover anchored to the flag icon, no header chrome, no explicit close button. Opens on hover, click, or tap; auto-dismisses 3 seconds after the pointer actually leaves it. Small/medium/large only change the flag icon's size (16/18/20px) — the tooltip's content, width, padding, and type are the same at every size.

Decisions applied here

Small/medium/large change only the flag icon's size (16/18/20px) — the tooltip itself (width, padding, "Out of Policy" title, message copy) is identical at every size · hover, click, and tap all open it, matching today's live pattern · no close button, so it auto-dismisses 3s after the pointer leaves the trigger (not 3s from the click) · keyboard focus reveals it via :focus-visible, and every close path calls blur() so a lingering keyboard focus ring can't keep it visually stuck open · placement (below/above/left) is a CSS position variant on the same panel, useful when the default below-anchor would run off the edge of a dense list or a narrow viewport · hotel card shown with every optional data slot filled in (reviews + colleague reviews, sustainability certified, coworker bookings, perk strip) to match the real card's maximum-density state. Full write-up: design-decisions.md.
