Placement
A · Under distance (recommended). Reads as a continuation of "0.06 miles away": the number tells you how far, the link shows where. Stars and distance always exist, so the link always lands in the same third row, and it fills the gap beside the photo when the sustainability line is missing. Costs about 16px of header height, which still fits inside the 77px photo.
B · On the photo. A small "Map" chip pinned to the thumbnail corner. Zero added height and obvious at a glance, but it sits on top of imagery that changes per hotel, the tap target is small, and a text link on a photo is the weakest option for contrast and accessibility.
C · Price row. Uses the empty space left of the price. Always pinned to the bottom of the card, so it never moves, and costs no height. The tradeoff is context: it sits next to the money and the out-of-policy flag instead of the location info, so it competes with the price for attention.

Behavior
Hover / focusThe matching pin on the map lifts slightly so users can find it before they commit to scrolling.
ClickSmooth-scrolls to the map, selects the pin and opens its hotel callout. The card itself does not navigate to the PDP.
Card clickAnywhere else on the card still opens the PDP. The link stops the click, the same way the out-of-policy flag does.
KeyboardA real button in tab order, labeled with the hotel name for screen readers, with a visible focus ring.
