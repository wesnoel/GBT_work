Hotel Quick Results
Progressive Rendering & SmartMix Explainability
Interactive wireframes for the SmartMix Panel — the new 3-column module that gets travelers to actionable hotel results in seconds instead of the current ~6s blank wait, while keeping preferred and negotiated rates fully visible and explaining why SmartMix ranked results the way it did. Built from the approved PRD, UX spec, and tech spec as the step before Figma.

Key decisions baked into these wireframes: 3-column panel order is Recommended · Expedia Only · Neg/Pref (per tech spec — supersedes the earlier "Egencia Preferred / Company Preferred / Recommended" naming from the July 8 exploration decks). Skeletons crossfade in place per column as each source responds, independently — no column waits for another. Deduplicated hotels are removed from the full list silently, with no "shown above" indicator. Amenity icons appear on full-list cards to satisfy the PRD's T3 acceptance criteria — see design-decisions.md for the full rationale, including one flagged conflict between the PRD and the approved UX spec worth resolving before Figma.
