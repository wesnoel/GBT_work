McKinsey Hotel Invoices

Clickable, low-fidelity wireframes for the agent console that runs the McKinsey direct-bill pilot — the tool GBT's Account/Servicing team uses to review hotel folio cases that don't pass automatic validation. Medium interactive: click through the major decision points (assign, approve, reopen, mark as chased) to see how state changes.

Source: PRD — McKinsey Hotel Folio Automation Reference: Solution Proposal (Bowie Brotosumpeno, v4) Fidelity: Low-fi, medium interactive Status: Draft for review

Design decisions (resolved from the UX spec / PM open questions)

Status visual language uses severity tiers of color, not 10 unique colors · self-assign is view-freely, confirm-before-acting · attachment viewer targets inline preview, with a download fallback · "Mark as Chased" is fixed reasons with an optional note · case list keeps 7 core columns fixed, PNR/FMNO behind a column picker · filtering is live with a clear empty state. Each decision is called out inline on the page where it applies. Full write-up: design-decisions.md.
