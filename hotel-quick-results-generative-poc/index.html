Hotel Mini Card Panel
Dynamic 1–3 column layout for the Featured / Egencia Preferred / Company Preferred panel
A layout that flexes between 1 and 3 columns depending on how many sources have results — a full-width horizontal carousel when there's only one, independent vertical-scroll peek columns when there are two or three — built from a smaller Hotel Mini Card so the panel doesn't compete for width with the full results list below it.

Key decisions: column count is a config/business-rule toggle here, not inferred live from result counts (see design-decisions.md). The 1-column carousel and 2/3-column vertical peek both use the same fixed-width Mini Card — no separate wide-card variant. Peek height is a permanent fixed height — the expands-on-interaction alternative was explored and dropped in favor of this. One QA catch along the way: the real product's "Company Preferred" badge renders as "Chat bhandar Preferred" — built here as the intended copy, flagged for engineering.

Generative UI POC (04): inverts the config-driven column toggle above into a context-driven one — see generative-poc.html for the schema, rules engine, and stubbed novel-scenario reasoning path.
