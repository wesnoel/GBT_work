Sustainability Certified Badge

Relabels the self-asserted "Eco-friendly" badge to "Sustainability certified," tied to the existing GDS/supplier certification feed. Two testable icon concepts, a hover tooltip naming the certification, and a click-to-open side sheet for multi-certification hotels. Card rebuilt from a reference hotel-card screenshot.

Source: PRD — Hotel Search Results Page UX spec: Confluence Fidelity: Low-fi, interactive Status: Exploration — icon pending usability testing

Icon concepts

A — Seal / checkmark

Concept A

A checkmark-in-circle glyph, standing in for a future ribbon/award/seal icon — reads as "verified" at badge size. No literal ribbon/seal glyph exists yet in the icon token set.

Open wireframe → B — Handshake

Concept B

A handshake glyph, evoking trust/partnership — already available in the icon token set.

Open wireframe →

Design decisions (resolved from the UX spec interview)

Icon direction: both concepts spec'd for testing, no single pick yet · tooltip opens on hover/focus (desktop) and tap (mobile) · sustainability filter nested under Amenities/Property in the real filter panel (a flat chip stands in here) · multi-certification hotels show the primary cert in the tooltip plus a "View all" affordance that opens a side sheet · zero-result state reuses the standard empty-state pattern. Full write-up: design-decisions.md.
