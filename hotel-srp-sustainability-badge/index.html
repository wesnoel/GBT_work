Sustainability Certified Badge

Relabels the self-asserted "Eco-friendly" badge to "Sustainability certified," tied to the existing GDS/supplier certification feed. Two testable icon concepts, a hover tooltip naming the certification, and a click-to-open side sheet for multi-certification hotels. Card rebuilt from a reference hotel-card screenshot.

Source: PRD — Hotel Search Results Page UX spec: Confluence Fidelity: Low-fi, interactive Status: Exploration — icon pending usability testing

Icon concepts

A — Seal / checkmark

Concept A

A checkmark-in-circle glyph — reads as "verified" at badge size.

Concept B

Same checkmark-in-circle icon as Concept A. Differs in interaction: hovering/focusing the badge previews the certification name before you click.

Open wireframe → C — Info link

Concept C

A plain text link with a circle-i info icon to its right — hovering/focusing either reveals the tooltip. No side sheet; the tooltip lists every certification directly.

Open wireframe →

Design decisions (resolved from the UX spec interview)

Icon direction: three concepts spec'd for testing, no single pick yet · Concepts A and B open a side sheet on click with the primary cert plus a "view all" hint for multi-cert hotels · Concept C uses the text-link + info-icon pattern with no side sheet, so its tooltip lists every certification directly · sustainability filter nested under Amenities/Property in the real filter panel (a flat chip stands in here) · zero-result state reuses the standard empty-state pattern. Full write-up: design-decisions.md.
